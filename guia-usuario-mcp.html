Guia Rápido

Como usar o MCP
NexusGOV Redmine

Passo a passo simples para conectar sua conta do Redmine ao Claude Code ou ao Codex CLI e começar a consultar tarefas e a API do NexusGOV (Swagger) por conversa — no Mac ou no Windows.

Versão para uso interno · Modo Portainer (recomendado, sem instalar nada)

O que é isso?

Este é um "conector" (chamado de MCP) que liga assistentes de IA como o Claude Code e o Codex CLI diretamente a dois sistemas da NexusGOV: o Redmine (tarefas) e a documentação da API do backend (Swagger). Depois de configurado uma única vez, você pode simplesmente conversar pedindo coisas como "quais são minhas tarefas em aberto?", "muda a tarefa 123 para em andamento" ou "procura no swagger o endpoint de login", e o assistente faz isso por você, sem precisar abrir o Redmine ou o Swagger no navegador.

Não precisa instalar nada. O servidor já roda centralizado no endereço abaixo. Você só precisa rodar um comando (ou colar um trecho de configuração), uma única vez, para conectar sua conta.

O que você vai precisar

  • O Claude Code ou o Codex CLI já instalado no seu computador (se não tiver, peça ajuda ao time técnico)
  • Acesso ao Redmine da NexusGOV com seu usuário e senha
Endereço do servidor: http://45.79.207.184:3001
Esse endereço já vem pronto nos comandos deste guia — não precisa trocar nada.

Passo 1 — Pegue sua chave de acesso pessoal no Redmine

Vale para Mac, Windows, Claude ou Codex — esse passo é sempre o mesmo:

1
Entre no Redmine normalmente pelo navegador, em https://sistemas.sofintech.com.br/redmine.
2
No canto superior direito, clique em Minha conta.
3
Procure por Chave de acesso à API e clique para mostrar (ou gerar, se ainda não existir). Copie esse código — ele é como uma senha especial só sua, não compartilhe com ninguém.

Passo 2 — Escolha seu assistente

Siga apenas a seção do assistente que você usa. Em todos os casos, troque SUA_KEY_PESSOAL pela chave copiada no Passo 1.

Claude Code

Mac

1
Abra o Terminal Aperte Cmd + Espaço, digite "Terminal" e aperte Enter.
2
Cole o comando abaixo e aperte Enter 
claude mcp add --transport sse --scope user nexusgov-redmine http://45.79.207.184:3001/sse --header "X-Redmine-Api-Key: SUA_KEY_PESSOAL"
3
Feche e abra o Claude Code de novo Isso faz ele reconhecer a nova conexão.

Windows

1
Abra o PowerShell Clique no menu Iniciar, digite "PowerShell" e aperte Enter.
2
Cole o comando abaixo e aperte Enter (é o mesmo comando do Mac) 
claude mcp add --transport sse --scope user nexusgov-redmine http://45.79.207.184:3001/sse --header "X-Redmine-Api-Key: SUA_KEY_PESSOAL"
3
Feche e abra o Claude Code de novo
Conferir se conectou (Mac ou Windows): 
claude mcp list
Deve aparecer nexusgov-redmine ... ✓ Connected
Codex CLI

No Codex, a conexão é feita editando um arquivo de configuração chamado config.toml. Não precisa saber programar — é só abrir o arquivo (ou criar, se não existir), colar o texto abaixo no final e salvar.

Mac

1
Localize o arquivo Ele fica em ~/.codex/config.toml (dentro da sua pasta de usuário, em uma pasta oculta chamada .codex). Se a pasta ou o arquivo não existirem, pode criar.

Windows

1
Localize o arquivo Ele fica em %USERPROFILE%\.codex\config.toml — normalmente algo como C:\Users\SEU_USUARIO\.codex\config.toml. Se a pasta ou o arquivo não existirem, pode criar.

Conteúdo a colar (Mac ou Windows)

2
Abra o arquivo em um editor de texto (Bloco de Notas no Windows, TextEdit no Mac) e cole no final: 
[mcp_servers.nexusgov-redmine]
url = "http://45.79.207.184:3001/sse"
headers = { "X-Redmine-Api-Key" = "SUA_KEY_PESSOAL" }
3
Salve o arquivo e reinicie o Codex CLI Feche a janela do terminal onde o Codex está rodando e abra de novo.
Se der erro de conexão (Claude ou Codex): confira se colou a chave sem espaços extras e se o endereço está exatamente http://45.79.207.184:3001/sse. Se continuar com problema, chame o time técnico.

O que você pode pedir

Depois de conectado, é só escrever em português normal, tanto no Claude Code quanto no Codex. Alguns exemplos:

Ver tarefas

"Liste minhas tarefas em aberto no projeto X"
"Mostra os detalhes da tarefa 4521"

Mudar status de uma tarefa

"Muda a tarefa 4521 para 'Em andamento'"
"Quais status existem no Redmine?"

Criar uma tarefa nova

"Cria uma tarefa nova no projeto X pra corrigir o botão de login"
Antes de criar, o assistente sempre vai mostrar o texto final da tarefa (assunto, descrição, tipo, prioridade, responsável) e pedir sua confirmação. Nada é criado sem você aprovar.

Editar uma tarefa existente

"Muda a prioridade da tarefa 4521 pra Urgente e atualiza a descrição"
Assim como na criação, o assistente mostra as mudanças propostas antes de salvar e só edita depois que você confirmar.

Consultar a documentação do sistema (Swagger)

"Procura no swagger algum endpoint de login"
"Mostra o contrato completo do endpoint de cadastro de usuário"

Dúvidas frequentes

Preciso repetir esse processo toda vez que abrir o assistente?

Não. A conexão é feita uma única vez por computador. Depois disso, ele já sabe se conectar ao Redmine automaticamente sempre que você abrir uma nova conversa.

Minha chave de API é segura?

Sim, ela fica salva só no seu computador e é usada apenas para identificar você no Redmine. Nunca compartilhe essa chave com outras pessoas.

Trocaram meu computador ou reinstalei o programa. E agora?

Basta repetir o Passo 2 (comando ou arquivo de configuração) na máquina nova.

Uso Mac num trabalho e Windows em casa, dá pra usar nos dois?

Sim. É só repetir a configuração em cada computador, usando sempre sua própria chave pessoal.

Quem eu chamo se algo não funcionar?

Entre em contato com o time técnico responsável pelo MCP NexusGOV Redmine.
